# MIK.COM

Простой сайт расписания занятий группы МИК-25.

## Что есть на сайте

- Расписание двух недель из файла `schedule.json`.
- Переключение между неделями.
- Светлая и тёмная темы.
- Выбор фонового изображения из встроенных обоев.
- Загрузка собственного изображения в качестве обоев.
- Сохранение темы, обоев и выбранной недели в браузере.

## Как устроен проект

```text
MIK.COM/
├── index.html
├── style.css
├── script.js
├── schedule.json
├── assets/
│   └── backgrounds/
└── images/
```

## Запуск локально

Откройте папку проекта в терминале и запустите локальный сервер:

```bash
python -m http.server 8081
```

Затем откройте в браузере:

`http://localhost:8081`

Не открывайте `index.html` напрямую через `file://`: браузеру нужен HTTP-сервер, чтобы загрузить `schedule.json`.

## Где менять расписание

Измените файл `schedule.json`. Данные разделены на недели, дни и занятия. Для каждого занятия можно указать номер, предмет, тип, преподавателя и аудиторию.

## Хранение настроек

Тема, выбранные обои, собственное изображение и номер недели сохраняются в `localStorage` текущего браузера. Эти настройки не синхронизируются между устройствами.

Проект не использует регистрацию, учётные записи, Supabase, серверную базу данных или API для загрузки материалов.
