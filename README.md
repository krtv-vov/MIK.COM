# MIK.COM

**MIK.COM** — учебный сайт для студентов. Здесь можно посмотреть расписание занятий, найти материалы по предметам и подготовиться к сессии.

🌐 **Сайт:** https://mik-com.vercel.app

## Возможности

- **Расписание** — просмотр занятий по дням и переключение между учебными неделями.
- **Лекции и материалы** — материалы сгруппированы по предметам; есть поиск по названию и описанию.
- **Предметы** — отдельный каталог учебных дисциплин.
- **Сессии и экзамены** — раздел с вопросами, документами и другими материалами для подготовки.
- **Добавление материалов** — можно прикрепить файл или добавить ссылку, указать название, предмет и описание.
- **Предпросмотр и скачивание** — поддерживаются разные типы файлов; доступные варианты предпросмотра зависят от формата.
- **Уведомления о новых материалах** — сайт отмечает материалы, которые ещё не просматривались на устройстве.
- **Оформление** — светлая и тёмная темы, выбор готовых обоев или собственного изображения.

Интерфейс адаптирован для телефонов, планшетов и компьютеров.

## Технологии

- HTML
- CSS
- JavaScript
- JSON для данных расписания
- Vercel для размещения сайта и серверных API
- Vercel Blob и Supabase используются в серверной части проекта для работы с материалами и данными

## Расписание

Данные расписания находятся в файле `schedule.json`. Чтобы изменить занятия, отредактируйте соответствующую неделю, день или пару в этом файле.

У каждой пары используются следующие поля:

- `number` — номер пары;
- `subject` — название предмета;
- `type` — тип занятия;
- `teacher` — преподаватель;
- `room` — аудитория.

После изменения файла и отправки обновлений в основную ветку сайта Vercel публикует новую версию проекта.

## Локальный запуск

Для просмотра сайта запустите локальный HTTP-сервер в корневой папке проекта. Например, если установлен Python:

```bash
python -m http.server 8080
```

Затем откройте в браузере:

```text
http://localhost:8080
```

Так можно проверить интерфейс и загрузку расписания. Для работы серверных функций из папки `api/` требуется соответствующая конфигурация окружения Vercel.

## Назначение проекта

Проект создан, чтобы учебное расписание и полезные материалы группы находились в одном удобном месте и были доступны с разных устройств.
